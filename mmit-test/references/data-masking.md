# 脱敏数据契约（硬门）

**硬门**：扫描失败拒绝开跑，或立即 Escalate 并隔离产物。禁止未脱敏数据入证据包。入口：`scripts/data_mask.py`。数据等级来自 `profile.data_classes`。

## 契约四步

1. **识别 `data_classes`**
2. **合成/脱敏种子**：保留**形状**，替换敏感值
3. **开跑前扫描**密钥、证件号、手机号、卡号、邮箱实值等；**失败拒绝开跑**
4. **生产抽样导出同样脱敏**；违规 → **立即 Escalate 并隔离产物**

## 1. 识别 data_classes

- 常见等级：`pii`、`payment`、`media`（及项目自有等级）。
- `data_classes` 为空或 `unknown` → **按最严规则**处理，不得当作「无敏感数据」。
- 识别错误/漏识按硬门失败处理。

## 2. 合成/脱敏种子

- **保留形状**：字段结构、长度分布、类型、枚举基数、关联关系（外键形状）保持可测。
- **替换敏感值**：证件号、手机号、卡号、邮箱、姓名实值、密钥等换成合成值。
- 种子哈希与夹具清单记入证据（DL 层）；见 `test-layers.md`。

## 3. 开跑前扫描

扫描对象（至少）：

| 类别 | 示例 |
|------|------|
| 密钥 | API key、token、私钥、连接串密码 |
| 证件号 | 身份证/护照号实值 |
| 手机号 | 真实手机号 |
| 卡号 | 银行卡/支付账号 |
| 邮箱实值 | 真实用户邮箱 |

- 扫描范围：夹具、种子、配置、日志样本、即将入证据包的文件。
- **失败 → 拒绝开跑**（B2 失败 → Escalate）。
- 扫描报告本身入证据，且不得包含命中的敏感实值。

## 4. 生产抽样与违规处置

- 从生产（或准生产）导出的样本**同样脱敏**后方可入包。
- 违规（发现未脱敏实值）：
  1. **立即 Escalate**（见 `escalate.md` 必须升级第 1 条）
  2. **隔离产物**：涉事文件移出证据包/交付物，不得传播
  3. 记录违规事实与处置，不得静默删除后继续
- 密钥泄露、越权访问生产数据 → 必须升级人工。

## 与裁决/交付的关系

- 裁决信号 `data_mask_clean` 必须为 true 才可进入 Allow 路径；false → 硬失败直决 Deny/Escalate。
- 证据包规范：禁止未脱敏敏感数据；伪造或不可追溯 → Deny 或 Escalate。
- 脱敏失败属于**硬失败**，不得被其他「好看」信号抵消。

## 检查清单

- [ ] `data_classes` 已识别（未知按最严）
- [ ] 种子合成且保留形状
- [ ] 开跑前扫描通过，报告已留存
- [ ] 生产样本已脱敏
- [ ] 证据包无敏感实值
