# M5 `desktop` — 桌面端模态

矩阵编号 **M5**。典型分级 **P0–P1**。层级 **ML**。执行面在 **E3**（真实或仿真设备/桌面环境）。

## 覆盖范围

- 安装包（安装/卸载）
- 签名与公证（signing / notarization）
- 更新（自动更新路径）
- 托盘 / 快捷键
- DPI（多缩放）
- 崩溃转储（crash dump）

制品形态来自 `profile.release_artifact`（如 `dmg`、`msix`）。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| installer verify | 安装包校验与安装/卸载结果 |
| update path | 更新路径执行记录（旧版→新版） |
| 签名状态 | 签名/公证验证输出（有效、过期、缺失） |

## 典型分级

| 现象 | 分级 |
|------|------|
| 无法安装启动、签名失效导致系统拒绝、崩溃丢数据 | P0 |
| 更新失败、主路径错误、DPI 导致关键 UI 不可用 | P1 |
| 托盘/快捷键次要问题、部分 DPI 瑕疵 | P2 |
| polish / 文档 | P3 |

## 探针提示

- 安装：干净环境安装 → 启动 → 卸载；记录每步退出状态。
- 签名公证：用系统验证工具输出原文；缺签名/公证按实际分发渠道要求定级。
- 更新：必须走真实 update path，不只覆盖安装。
- DPI：至少两档缩放；记录截图或布局探针结果。
- 崩溃转储：触发可收集场景时验证 dump 生成与路径；无崩溃场景则记盲区而非 PASS。
- 缺桌面环境/OS 变体 → Blind Spot；阻塞 P0 路径 → Escalate。

## 回归固化

来源缺陷面 `desktop` → **安装启动冒烟、关键流**。

## 禁止

- 只测便携/开发模式运行，不测安装包
- 忽略签名状态
- 无 update path 证据宣称更新可用
