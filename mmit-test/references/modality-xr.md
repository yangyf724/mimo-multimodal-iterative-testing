# M12 `xr` — XR 模态

矩阵编号 **M12**。典型分级 **P0–P1**。层级 **ML**。执行面 **E3**（真实 HMD 或仿真；仿真必须标注 `sim`）。设备来自 `profile.devices`（如 `quest3`）。

## 覆盖范围

- 会话生命周期（进入/暂停/恢复/退出）
- 追踪丢失（tracking loss）与恢复
- 交互（控制器/手柄/手势）
- 帧率
- 舒适度（comfort，晕动相关）

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| session 日志 | 会话生命周期与事件日志 |
| 帧率采样 | 帧率/掉帧采样数据 |
| sim/real 标注 | 每条结果标明仿真或真机 |

## 典型分级

| 现象 | 分级 |
|------|------|
| 崩溃、追踪完全不可用、安全相关（跌倒/强不适） | P0 |
| 主交互路径失败、严重掉帧、追踪丢失后无法恢复 | P1 |
| 舒适度瑕疵、部分交互不稳 | P2 |
| polish | P3 |

## 探针提示

- 会话：冷进入、中断（来电/系统面板）、恢复、退出；每步有 session 日志。
- 追踪丢失：模拟丢失场景（遮挡摄像头/超界），验证恢复与用户提示。
- 交互：主交互（选择/移动/抓取）路径；记录失败率。
- 帧率：采样窗覆盖代表性场景；记录均值/P95 与掉帧次数。
- 舒适度：固定场景下的可述规则（加速方式、视野遮罩、闪烁）；纯主观 → P3/Deferred。
- **sim/real 必须标注**；仅仿真覆盖时 `optional_degraded` + Blind Spot。
- 缺 HMD：optional + Blind Spot；阻塞 P0 路径 → Escalate。

## 回归固化

来源缺陷面 `xr` → **可播/加载/尺寸/预算断言**（与 AV/Canvas/3D 同族）；关键交互另补 session 断言。

## 禁止

- 仿真结果冒充真机
- 无帧率采样宣称性能达标
- 缺设备却标 required 通过
