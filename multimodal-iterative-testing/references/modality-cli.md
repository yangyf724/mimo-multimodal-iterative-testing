# M6 `cli` — 命令行模态

矩阵编号 **M6**。典型分级 **P1**。层级 **ML**。适合 E0/E1 非交互执行。

## 覆盖范围

- help / 退出码
- 管道与重定向（stdin/stdout/stderr）
- 配置发现（配置文件、环境变量、默认值）
- 非交互 CI 模式（无 TTY）

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| golden exit/stdout/stderr | 黄金退出码与标准输出/错误对照 |
| flag 矩阵 | 关键 flag 组合 × 结果表 |

## 典型分级

| 现象 | 分级 |
|------|------|
| （罕见）导致数据丢失/安全问题的 CLI 路径 | P0 |
| 错误退出码、stdout/stderr 混流破坏管道、配置发现错误 | P1 |
| help 文案瑕疵、次要 flag 偏差 | P2 |
| 文档/示例问题 | P3 |

## 探针提示

- 退出码是契约：0 与非 0 语义固定；用例覆盖成功、用户错误、内部错误。
- 管道：`cmd | next`、重定向、stdin 消费；检查 stdout 是否被日志污染。
- 配置发现顺序（flag > env > file > default）逐档验证；记录实际生效值来源。
- 非交互：设置无 TTY 环境（CI 常见）跑关键命令，禁止假定交互确认。
- help/usage：`--help` 退出码与内容稳定。
- 所有 golden 结果绑定当前构建的二进制/入口（`rc_sha`）。

## 回归固化

来源缺陷面 `cli` → **golden exit/stdout/stderr**。

## 禁止

- 只人工目测输出
- 退出码从不校验
- 交互式跑通就当 CI 可用
