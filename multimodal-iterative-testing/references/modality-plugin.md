# M13 `plugin` — 插件模态

矩阵编号 **M13**。典型分级 **P0–P1**。层级 **ML**。宿主来自 `profile.plugins`（如 `vscode-ext`）。

## 覆盖范围

- 宿主 API（host API）
- 安装 / 升级 / 卸载
- 权限
- 冲突（与其他插件/扩展）
- 沙箱（sandbox 限制）

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| host-API pin | 宿主 API 版本/能力固定与兼容结果 |
| install/upgrade 流 | 安装与升级流程执行记录（含卸载） |

## 典型分级

| 现象 | 分级 |
|------|------|
| 沙箱逃逸/越权、安装即崩溃、宿主被破坏 | P0 |
| 升级失败、主功能错误、权限声明与实际不符 | P1 |
| 与次要插件冲突、非关键 API 弃用警告 | P2 |
| 文档/元数据瑕疵 | P3 |

## 探针提示

- host-API pin：固定宿主版本与目标 API 集；记录废弃 API 使用。
- 安装流：干净宿主安装 → 激活 → 使用 → 升级 → 卸载；逐步留证。
- 升级：从上一发布版升级到 RC，验证状态迁移与数据兼容。
- 权限：声明 vs 实际请求；多余权限记缺陷。
- 冲突：与代表性共存插件同装；记录加载顺序与错误。
- 沙箱：验证文件/网络/进程访问边界；越权按 P0 评估。
- 缺宿主环境 → Blind Spot；阻塞 P0 路径 → Escalate。

## 回归固化

来源缺陷面 `plugin` → **host-API pin、install/upgrade**。

## 禁止

- 只在开发宿主（如 Extension Development Host）跑通即 PASS
- 跳过升级/卸载路径
- 权限越界不报
