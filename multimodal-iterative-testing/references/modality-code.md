# M1 `code` — 代码模态

矩阵编号 **M1**。典型分级 **P0–P1**。层级以 **ML** 为主，夹具/种子问题记 **DL**。

## 覆盖范围

- 单元测试、集成测试
- 类型检查、lint
- 依赖漏洞（audit / 供应链扫描）
- 资源与并发（泄漏、竞态、句柄/内存）

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| 测试退出码 | 单测/集成测命令退出码与汇总（通过/失败/跳过计数） |
| lint/audit 报告 | lint、类型检查、依赖漏洞报告原文或机读导出 |

无上述机读证据 → 不得判 PASS。`unavailable` ≠ 通过。

## 典型分级

| 现象 | 分级 |
|------|------|
| 崩溃、数据丢失、安全漏洞、鉴权绕过 | P0 |
| 主路径错误、错误数据、严重性能回退 | P1 |
| 次要路径问题、可恢复体验差 | P2 |
| 文案/文档/polish | P3 |

（完整定义见 `defect-severity.md`；本表仅列本模态常见落点。）

## 探针提示

- 以**干净基线**跑测试与 lint，记录完整命令行、退出码、工具版本。
- 依赖漏洞：记录扫描器与漏洞库版本；高危未修按 P0/P1 评估。
- 资源与并发：泄漏/竞态用可重复用例；偶现须标注复现率，不得当稳定 PASS。
- 跳过（skip）的用例计入盲区，不得充入通过数。
- 结果绑定 `rc_sha`；源码修改后旧退出码不可复用。

## 回归固化

来源缺陷面 `code` → **最小复现单测/集成测**（见 `fix-regression.md`）。

## 禁止

- 无退出码/报告的口头「测过了」
- 失败用例改 skip 后宣称绿
- 跨 RC 复用测试结果
