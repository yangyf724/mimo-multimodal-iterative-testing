# M10 `canvas` — 画布模态

矩阵编号 **M10**。典型分级 **P1–P2**。层级 **ML**。复用 MIBG canvas 探针实现。

## 覆盖范围

- 安全区（safe area）
- 图层/层级（layering）
- 导出尺寸
- 资产分辨率

适用于设计画布、图表画布、编辑器画布等以场景+导出为交付的表面。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| scene 与导出交叉验证 | 场景状态与导出产物尺寸/内容的交叉核对结果 |

交叉验证至少覆盖：导出尺寸 vs 声明尺寸、可见层级 vs 导出层级、关键资产分辨率。

## 典型分级

| 现象 | 分级 |
|------|------|
| （罕见）数据丢失（导出损坏/内容缺失） | P0–P1 |
| 导出尺寸错误、层级遮挡关键内容、安全区裁切关键元素 | P1 |
| 资产模糊、次要层级瑕疵 | P2 |
| 纯审美主观判断 | P3 / Deferred |

## 探针提示

- 安全区：在带 notch/圆角约束的视口下检查关键元素是否被裁。
- 层级：遮挡/穿透/点击命中；记录 layer 顺序断言。
- 导出尺寸：多档目标尺寸（1x/2x/自定义）与像素级尺寸读数。
- 资产分辨率：位图资产实际分辨率 vs 逻辑尺寸，低于阈值记缺陷。
- 主观视觉结论须可述规则或 k 次一致，否则 P3/Deferred。
- 场景与导出**必须交叉**：只看场景或只看导出都不够 Floor。

## 回归固化

来源缺陷面 `canvas` → **可播/加载/尺寸/预算断言**（与 AV/3D/XR 同族）。

## 禁止

- 只截图场景不验证导出
- 主观审美直接升 P0/P1
- 无尺寸读数的「看起来对」
