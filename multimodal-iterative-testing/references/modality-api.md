# M2 `api` — 接口模态

矩阵编号 **M2**。典型分级 **P0–P1**。层级以 **ML** 为主；契约与文档数字不一致记 **FL**。

## 覆盖范围

- 契约（OpenAPI / proto 等）一致性
- 鉴权与授权
- 错误模型
- 幂等
- 超时、限流
- 版本兼容（含 breaking change）

契约源来自 `profile.contract_apis`。无契约源时降级为黑盒接口探针，并记 Blind Spot。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| contract diff | 契约对比结果（新增/破坏性变更/未审查 breaking） |
| authz 矩阵 | 主体 × 动作 × 资源的允许/拒绝结果表 |
| 黄金响应 | 关键端点的黄金响应（golden）对照 |

## 典型分级

| 现象 | 分级 |
|------|------|
| 鉴权绕过、数据泄露、核心接口不可用 | P0 |
| 主路径错误、错误数据、契约破坏未审查 | P1 |
| 次要端点问题、可恢复错误码偏差 | P2 |
| 文档/示例偏差 | P3 |

## 探针提示

- 契约 diff 须区分 additive / breaking；`contract_breaking_unreviewed=true` 时不得 Allow 无条件放行。
- 鉴权：匿名、低权、越权、过期令牌至少各一档；结果落 authz 矩阵。
- 错误模型：状态码/错误码/消息结构稳定；禁止把异常吞成 200。
- 幂等：同一请求重复提交结果可预期；记录幂等键行为。
- 超时/限流：记录阈值与客户端可见行为（重试、429、退避）。
- 版本兼容：旧客户端路径冒烟；破坏性变更必须显式列出。

## 回归固化

来源缺陷面 `api` → **contract / CDC、黄金响应**。

## 禁止

- 仅用「curl 200」当黄金证据
- 破坏性变更未审查即宣称兼容
- 跳过鉴权矩阵只测快乐路径
