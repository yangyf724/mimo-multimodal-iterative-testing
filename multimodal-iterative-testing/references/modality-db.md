# M7 `db` — 数据库模态

矩阵编号 **M7**。典型分级 **P0–P1**。层级 **ML**；夹具/种子质量记 **DL**。执行面通常在 **E1**（生产等价拓扑中的数据存储）。

## 覆盖范围

- 迁移（migrate）
- 约束（唯一/外键/检查约束）
- 查询（正确性与计划）
- 备份恢复
- 锁与慢查询

拓扑中的存储组件来自 `profile.topology`（如 `postgres`）。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| migrate dry-run | 迁移 dry-run / 执行结果与版本步进记录 |
| restore smoke | 备份恢复冒烟结果 |

## 典型分级

| 现象 | 分级 |
|------|------|
| 数据丢失、迁移破坏数据、恢复失败 | P0 |
| 约束缺失导致错误数据、主查询错误、锁死主路径 | P1 |
| 慢查询明显回退、次要查询问题 | P2 |
| 脚本/文档瑕疵 | P3 |

## 探针提示

- 迁移：升级与（若支持）回滚路径；`migrate dry-run` 先行，再在 E1 副本执行。
- 约束：故意插入违规数据，验证拒绝；无约束的脏数据入口记缺陷。
- 查询：黄金查询结果对照；关注 NULL/时区/排序稳定性。
- 备份恢复：真实 restore 冒烟，不只验证「备份任务成功」。
- 锁与慢查询：长事务/并发写入下观察锁等待；记录慢查询阈值与样本。
- 夹具与种子属 DL：形状须与脱敏种子一致（见 `data-masking.md`）。

## 回归固化

来源缺陷面 `db` → **migrate + query/constraint fixture**。

## 禁止

- 在生产库上做破坏性迁移试验
- 无 restore 证据宣称可恢复
- 用开发库结果替代 E1
