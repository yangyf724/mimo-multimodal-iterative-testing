# M9 `av` — 音视频模态

矩阵编号 **M9**。典型分级 **P1–P2**。层级 **ML**；导出参数与文档不一致可记 **FL**。

## 覆盖范围

- 可解码、可播
- 时长对齐（音画同步）
- 响度（loudness）
- 字幕与音轨
- 导出参数（编码、容器、码率等）

媒体目录线索来自 Profile Scan（媒体目录/资产清单）。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| 元数据探针 | 时长、编码、声道、响度等元数据输出 |
| 可播冒烟 | 解码/播放冒烟结果（成功/失败/卡顿点） |
| 导出参数 | 导出产物参数与目标规格对照 |

## 典型分级

| 现象 | 分级 |
|------|------|
| （罕见）导致数据丢失/安全问题 | P0 |
| 无法解码播放、音画严重不同步、导出损坏 | P1 |
| 响度偏差、字幕瑕疵、部分设备兼容问题 | P2 |
| 非阻断参数偏好、文档 | P3 |

## 探针提示

- 先元数据后播放：ffprobe/等价工具输出机读留存。
- 时长对齐：比较音轨/视频轨时长与偏移；超出可感阈值记缺陷。
- 响度：记录测量标准（如 LUFS）与目标范围。
- 字幕/音轨：存在性、语言标签、切换路径。
- 导出：参数矩阵（容器/编码/分辨率/码率）对照规格；产物哈希入证。
- 大文件注意证据体积：用元数据 + 关键帧/短样例，避免整段入包。

## 回归固化

来源缺陷面 `av` → **可播/加载/尺寸/预算断言**（与 Canvas/3D/XR 同族）。

## 禁止

- 只凭「能打开」无元数据宣称可播
- 无导出参数证据宣称规格达标
- 未脱敏音视频入证据包（若含敏感内容）
