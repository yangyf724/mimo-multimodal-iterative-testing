# M4 `mobile` — 移动端模态

矩阵编号 **M4**。典型分级 **P0–P1**。层级 **ML**；设备覆盖率/仿真降级影响裁决信号。执行面在 **E3**（真实或仿真设备）。

## 覆盖范围

- 安装与启动
- 权限（系统权限流）
- 深链（deep link）
- 恢复（进程被杀/后台恢复）
- 推送
- 安全区（notch / 刘海 / 手势条）

设备清单来自 `profile.devices`（如 `ios-sim,android-emu`）。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| 冷启动日志 | 安装/冷启动过程日志与结果 |
| 权限流 | 权限弹窗与授予/拒绝路径记录 |
| 设备矩阵 | 机型 × OS × 结果表；仿真须标注 `sim` |

## 典型分级

| 现象 | 分级 |
|------|------|
| 无法安装启动、权限导致核心不可用、崩溃 | P0 |
| 主路径错误、推送/深链关键失败、安全区遮挡关键操作 | P1 |
| 部分设备问题、体验差可恢复 | P2 |
| 非阻断 polish | P3 |

## 探针提示

- 真机：记录型号、OS、DPI、区域；仿真必须标注 `sim`，覆盖率单独统计。
- 权限：授予与拒绝两分支都要走；拒绝后的降级体验记入结果。
- 深链：冷启动深链与热启动深链分开验证。
- 恢复：模拟进程终止后恢复状态是否正确。
- 推送：到达、点击、后台/前台分支。
- 缺设备 → optional + Blind Spot；**若阻塞 P0 路径 → Escalate**。

## 回归固化

来源缺陷面 `mobile` → **安装启动冒烟、关键流**。

## 禁止

- 只用仿真结果宣称真机覆盖
- 无冷启动日志的安装/启动 PASS
- 缺设备却标 required 通过
