# M11 `3d` — 三维/建模模态

矩阵编号 **M11**。典型分级 **P1**。层级 **ML**。

## 覆盖范围

- 加载（模型/场景可加载）
- 法线 / UV / 材质
- 面数预算（polygon budget）
- 动画
- 导出格式

适用于 3D 资产管道、建模导出、WebGL/引擎加载路径等。

## Evidence Floor（最低证据）

| 证据 | 说明 |
|------|------|
| 加载日志 | 模型/场景加载过程日志（成功、警告、失败） |
| 预算计数 | 面数/顶点/材质/贴图等计数与预算对照 |

## 典型分级

| 现象 | 分级 |
|------|------|
| （罕见）加载崩溃导致不可用 | P0 |
| 无法加载、法线/UV 错误导致明显破面、超预算导致不可用 | P1 |
| 材质轻微偏差、动画瑕疵 | P2 |
| 非阻断 polish | P3 |

## 探针提示

- 加载：记录加载器/引擎版本、警告与错误原文；失败不得静默跳过。
- 法线/UV：用检查视图或等价断言（硬边、接缝、阴影伪影）；能自动判定的写规则。
- 材质：贴图缺失、色彩空间、透明度排序问题。
- 面数预算：对代表性资产计数；超预算按目标运行环境（移动/桌面/VR）定级。
- 动画：播放完整性、循环边界、根运动；记录时长与关键帧数。
- 导出格式：目标格式（glTF/FBX/USD 等）可再加载；导出后再加载一次作闭环。

## 回归固化

来源缺陷面 `3d` → **可播/加载/尺寸/预算断言**（与 AV/Canvas/XR 同族）。

## 禁止

- 只在 DCC 工具里目测，不验证运行时加载
- 无预算计数宣称性能可接受
- 导出后不再加载就当闭环
